# ขยายภาพให้คมชัด (AI Upscaler)

เว็บแอปขยายภาพด้วย AI ที่ประมวลผล **ในเครื่องของผู้ใช้เอง** ผ่านเบราว์เซอร์
รูปไม่ถูกส่งไปเซิร์ฟเวอร์ใด ไม่มีค่ารายเดือน ไม่จำกัดจำนวนรูป และไม่ต้องมีการ์ดจอแยก

## ใช้งานอย่างไร

1. เปิดหน้าเว็บ (ต้องเปิดผ่านลิงก์เว็บ เปิดไฟล์ `index.html` ตรง ๆ จากเครื่องไม่ได้)
2. ลากรูปมาวาง หรือกดเลือกไฟล์ (เลือกหลายรูปได้)
3. เลือกขนาด: 2 / 4 / 8 / 16 เท่า หรือกำหนดด้านยาวเป็นพิกเซล
4. กด "เริ่มขยายภาพ" รอจนเสร็จ แล้วกด "ดาวน์โหลด"

แนะนำเบราว์เซอร์ Chrome หรือ Edge รุ่นปัจจุบัน

## ข้อจำกัดที่ควรรู้

- เวลาขึ้นกับจำนวนพิกเซลของ **ภาพต้นฉบับ** และความเร็ว CPU เป็นหลัก (ขยายเกิน 4 เท่าจะช้าลงมากเพราะต้องขยายสองรอบ)
- เพดานผลลัพธ์: ด้านยาวไม่เกิน 32,767 พิกเซล และรวมไม่เกิน 268 ล้านพิกเซล (เพดานของ Chrome/Edge)
  (แก้ได้ที่ `js/config.js` แต่ถ้าตั้งสูงเกินหน่วยความจำเครื่อง เบราว์เซอร์จะแจ้งว่าสร้างภาพไม่ได้)
- AI "เติม" รายละเอียดที่ไม่มีในต้นฉบับ ตัวหนังสือเล็ก โลโก้ และใบหน้าอาจเพี้ยนจากของจริง
- ปิดหรือโหลดหน้าใหม่ รายการและผลลัพธ์ที่ยังไม่ดาวน์โหลดจะหายไป (ไม่มีการเก็บรูปไว้ที่ใด)

## โครงสร้างไฟล์

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html`, `css/styles.css` | หน้าตาเว็บ |
| `js/config.js` | **ค่าตั้งต้นทั้งหมด** (ขนาดชิ้น, เพดานขนาด, ตัวเลือกจำนวนเท่า) — ปรับพฤติกรรมให้แก้ที่นี่ |
| `js/tiling.js` | กฎการคำนวณ: ขนาดผลลัพธ์ ขั้นตอนขยาย การแบ่งภาพเป็นชิ้น |
| `js/app.js` | หน้าจอ: รายการรูป ปุ่ม ความคืบหน้า ตัวเปรียบเทียบก่อน/หลัง |
| `js/upscale-worker.js` | ส่วนประมวลผล AI (ทำงานเบื้องหลัง) |
| `js/isolation.js`, `sw.js`, `_headers` | เปิดโหมดใช้ CPU หลายแกน (เร็วขึ้นหลายเท่า) |
| `models/` | โมเดล AI — Real-ESRGAN `realesr-general-x4v3` (BSD-3-Clause) |
| `vendor/ort/` | ONNX Runtime Web 1.31.1 (MIT) — ตัวรันโมเดลในเบราว์เซอร์ |
| `tools/` | เครื่องมือสำหรับผู้พัฒนา: แปลงโมเดล และเซิร์ฟเวอร์ทดสอบ (`node tools/serve.mjs`) |

## การทำงานโดยย่อ

ภาพถูกตัดเป็นชิ้น 256 พิกเซล (ซ้อนขอบ 16 พิกเซลกันรอยต่อ) ส่งให้โมเดลขยายทีละชิ้น 4 เท่า
แล้วประกอบกลับ ขนาดที่ไม่เกิน 4 เท่า แต่ละชิ้นถูกย่อลงสู่ขนาดเป้าหมายทันทีตอนประกอบ
(ไม่สร้างภาพ 4 เท่าเต็มใบก่อน จึงไม่เปลืองหน่วยความจำ) ขนาดที่เกิน 4 เท่าขยายสองรอบ
โปรแกรมลองใช้ GPU ในเครื่อง (WebGPU) ก่อน และจะใช้ก็ต่อเมื่อผลตรงกับ CPU และเร็วกว่าจริง
ถ้าไม่ผ่านจะใช้ CPU หลายแกนแทน
